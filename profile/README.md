### Fair by design

- Every value draw is bound to a public randomness round and can be replayed by anyone.
- Every spend and every gain is written to a hash-chained ledger that players can verify in game.
- The rules engine that decides hunts, draws and rewards will be published here for public audit.

### Security

Found a vulnerability? Write to **hi@cot.gg**. Please do not open a public issue for security reports.

The team never sends the first DM, never asks for a seed phrase and never asks you to connect a wallet outside cot.gg.
